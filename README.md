# Jetpack Joyride Takeover

**Minecraft** × Jetpack Joyride · visual · idea by the team

Bring Jetpack Joyride into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned Minecraft into Jetpack Joyride: a machine gun jetpack, lightning zappers, missiles and scientists that pop into coins. The zappers got me.

## Install

Install Fabric for Minecraft 26.3 with Fabric API, then drop the mod jar into your mods folder and start a world. You spawn wearing the Machine Gun Jetpack in a lab tunnel: hold Jump to fly and shoot, grab coins, dodge zappers and missiles.
